## Systematic Implementation Matrix

| Task | Priority | File | Change | Reason |
| :--- | :---: | :--- | :--- | :--- |
| **T1. Fix Fatal JSON-LD Syntax Error** | **CRITICAL** | `resources/views/layouts/app.blade.php` | Remove trailing comma before `]` in `areaServed` array of `TravelAgency/LocalBusiness` schema. | Unblocks JSON parsing for Googlebot and validates Global Schema across all pages. |
| **T2. Secure Maintenance & Cache Routes** | **CRITICAL** | `routes/web.php` | Wrap `/clear` and `/set-ads` routes with admin authorization or signature tokens, removing public access. | Eliminates critical stability risk where web crawlers or scrapers wipe server sessions and application cache. |
| **T3. Enforce Canonical Domain in Sitemaps** | **HIGH** | `app/Http/Controllers/SitemapController.php` | Bind all sitemap URLs to `config('app.url')` (`https://dubaitourbook.com`), preventing localhost fallback. | Ensures search engines index valid production URLs rather than `127.0.0.1:8003`. |
| **T4. Streamline Sitemap Hreflangs & Payload** | **HIGH** | `app/Http/Controllers/SitemapController.php`, `resources/views/sitemap.blade.php` | Retain only true unique language versions (`en`, `ar`, `ru`) and `x-default`, eliminating duplicate regional alternates. | Reduces sitemap payload by 75% and resolves Google Search Console duplicate hreflang warnings. |
| **T5.
